3. Problem Solving: Vercel Edge vs. Serverless Lambda

The Challenge & Diagnostic Process

During initial Vercel deployment, Vercel detected a root server.js file and misclassified the project as a Node.js Serverless Lambda rather than a Static Edge Site. This caused all static assets under /assets/ (stylesheets, scripts, 3D textures) to return 404 Not Found errors.

Resolution: Using network header tracing, the failure was identified immediately. I updated vercel.json to explicitly declare "framework": null (enforcing pure Edge CDN static file delivery), relocated the self-hosted Node server into server/server.js, and pushed to GitHub. Vercel automatically triggered an edge redeployment, immediately achieving 100% 200 OK asset responses.

4. Enterprise Cybersecurity Protections

The application incorporates defensive hardening across edge hosts (Vercel/Netlify), container environments (Nginx/Docker), and standalone runtimes:

Protection Mechanism Threat Mitigated Implementation Details
Content Security Policy (CSP) Cross-Site Scripting (XSS), Data Injection Strict directive restricting script/style execution to self and verified CDNs while permitting WebGL shaders.
Anti-Clickjacking Controls UI Redress / Clickjacking Attacks Enforced X-Frame-Options: DENY, frame-ancestors 'none', and client-side framebusting defense.
MIME Sniffing Prevention MIME Confusion Attacks Strict X-Content-Type-Options: nosniff headers attached to all HTML, CSS, JS, and image responses.
Transport Layer Security Man-In-The-Middle (MITM) Strict-Transport-Security (HSTS) with 2-year lifetime (max-age=63072000; includeSubDomains; preload).
Rate Limiting & Anti-DDoS Scraping Floods, Brute Force Sliding-window IP rate limiter (300 req/min per IP) in server.js and burst limiting in nginx.conf.
Path Traversal Defense Local File Inclusion (LFI) Strict path canonicalization and containment verification preventing directory escapes.
RFC 9116 Compliance Vulnerability Reporting Published machine-readable disclosure policy at /.well-known/security.txt and SECURITY.md.
